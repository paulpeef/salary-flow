Salary Flow теперь использует одну подпись приложения для официальных обновлений с GitHub. Это позволяет macOS узнавать новые версии при проверке ранее выданного доступа к управлению и экрану. После перехода со старой версии может понадобиться один раз подтвердить разрешение заново.

Исправлена высота панели в строке меню. Когда начинается запись или обработка встречи, кнопки остаются на месте. Подробности Spokenly, Zoom и чата открываются через «Состояние записи».

Для первой установки на Mac с Apple Silicon распакуйте архив и перенесите Salary Flow в «Программы». Сборка без нотариализации Apple. Если macOS блокирует первое открытие, для официального архива можно разрешить запуск этого приложения в «Конфиденциальность и безопасность». [Инструкция Apple](https://support.apple.com/ru-ru/102445).
