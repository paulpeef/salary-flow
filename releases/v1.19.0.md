При обычном копировании расшифровки тайм-коды реплик скрыты. В файлах встречи они сохранены. В контекстном меню кнопки копирования можно выбрать «Скопировать с тайм-кодами».

Перед записью Salary Flow проверяет доступ к экрану для чтения рамок Zoom. В разговоре один на один приложение использует список участников и отдельную дорожку собеседника. Своё имя в Zoom можно указать в настройках встреч.

В групповых звонках Salary Flow сравнивает голос с подтверждёнными образцами текущей встречи на Mac. При неоднозначном совпадении сохраняется обычная метка голоса.

Для повторяющихся встреч можно прослушать образцы и подтвердить сохранение профиля на Mac. В настройках доступна проверка качества имён по отдельным дорожкам Zoom.

Из Google Meet можно импортировать готовую штатную расшифровку с именами участников через OAuth-клиент Desktop app.

Обновление доступно в Настройки → Приложение → Проверить сейчас.
